# Signal AI 🚀

**Live forex trading signal generator using MACD + Bollinger Bands + ADX**

### 🔗 Live Demo
**[Click here to use the app](https://nwankire.github.io/SIGNAL-AI/)**

### ✨ Features
- Real-time EUR/USD, GBP/USD, USD/JPY prices
- BUY / SELL / WAIT signals with % strength gauge
- 5min, 15min, 1H timeframes
- Built with HTML, CSS, JavaScript
- 100% free to use

### 📊 Strategy Logic
- **BUY:** MACD cross up + Price touches lower BB + ADX > 25
- **SELL:** MACD cross down + Price touches upper BB + ADX > 25  
- **WAIT:** No clear setup
